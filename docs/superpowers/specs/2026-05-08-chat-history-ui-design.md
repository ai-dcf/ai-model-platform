# 对话历史 UI 重构设计规范

## 1. 目标与背景

当前 `/chat` 页面的历史对话列表采用了悬浮面板设计，导致其在页面上层叠，不仅视觉上显得突兀，还存在遮挡顶部导航栏的风险。
本设计的目的是参考业内主流的 AI 对话界面（如 DeepSeek、ChatGPT），将历史记录面板重构为**可折叠的左侧边栏**，并优化内部元素的排版与交互。

## 2. 整体布局设计 (Layout)

页面采用 **全局顶部导航 + 左右分栏** 的响应式结构：

```text
+---------------------------------------------------+
| 全局顶部导航栏 (Navbar - 保持原样, 宽度 100%)       |
+-----------+---------------------------------------+
| 侧边栏     | 主聊天区域 (Main Chat Area)            |
| (Sidebar) |                                       |
|           | [模型选择器]                           |
| [新对话]   |                                       |
|           |                                       |
| - 今天     |                                       |
|   会话 A   | (消息滚动区)                           |
|   会话 B   |                                       |
|           |                                       |
| - 昨天     |                                       |
|   会话 C   |                                       |
|           |                                       |
|           | +-----------------------------------+ |
|           | | 消息输入框                         | |
|           | +-----------------------------------+ |
+-----------+---------------------------------------+
```

*   **导航栏**：页面最上方保留原有的 `Navbar` 组件。
*   **内容区**：`h-[calc(100vh-navbarHeight)]`，采用 `flex row`。
*   **侧边栏响应式**：在大屏幕下默认展开（固定宽度 `w-64` 或 `260px`），可通过按钮折叠至 `w-0`；在移动端下可作为抽屉 (Drawer) 滑出。

## 3. 组件细节设计

### 3.1 可折叠左侧边栏 (Sidebar)

*   **折叠控制**：
    *   侧边栏内部右上角或左上角提供折叠按钮（`PanelLeftClose`）。
    *   当侧边栏折叠时，主聊天区域左上角出现展开按钮（`PanelLeftOpen`）。
*   **核心操作区**：
    *   顶部提供一个通栏的 `[+ 开启新对话]` 大按钮，强调核心行为。
*   **历史记录列表 (按时间分组)**：
    *   取消简单的倒序平铺，采用分组展示。
    *   **分组维度**：`今天`、`昨天`、`7天内`、`30天内`、`更早`。
    *   **视觉样式**：分组标题使用小号弱化文本 (`text-xs text-text-dim`)，会话项悬停时出现 `...` 菜单，用于触发重命名或删除操作。

### 3.2 主聊天区域 (Main Chat Area)

*   **模型选择器 (Model Selector)**：
    *   从原有的侧边栏顶部移除。
    *   移动至主聊天区域的**左上角**（如果侧边栏折叠，则在展开按钮的右侧）。
    *   采用轻量级的下拉菜单样式，不干扰聊天内容的阅读。
*   **聊天内容与输入框**：
    *   保持现有的自适应高度和底部输入框位置，但其容器宽度将随着侧边栏的折叠/展开而平滑过渡（`transition-all`）。

## 4. 数据与状态管理

*   **UI 状态**：
    *   `isSidebarOpen`: `boolean`，控制侧边栏的展开与收起。
*   **数据转换 (Grouping Logic)**：
    *   新增工具函数 `groupConversationsByDate(conversations: Conversation[])`。
    *   使用 `dayjs` 或原生 `Date` API，将 `conversation.createdAt` 与当前时间比对，返回一个分组后的数据结构：
        ```typescript
        type GroupedConversations = {
          label: string; // '今天', '昨天', '7天内' 等
          items: Conversation[];
        }[]
        ```

## 5. 注意事项
*   **动画平滑度**：侧边栏的展开折叠需使用 CSS Transition，确保主体区域宽度变化平滑。
*   **主题兼容**：使用系统已定义的 CSS 变量（如 `bg-surface`、`text-text-muted`）以保持极简艺术风格。
