# 图片页动态比例渲染设计文档

> **创建时间**：2026-05-08
> **功能名称**：图片页根据模型能力动态渲染支持的宽高比
> **状态**：待实施

## 1. 功能概述

### 1.1 背景

当前 `app/image/page.tsx` 中的比例按钮由本地常量 `aspectRatios` 写死，页面仅展示：

- `1:1`
- `4:3`
- `3:4`
- `16:9`
- `9:16`

而 `lib/image-vendor-presets.ts` 中已经为 `doubao-seedream-5.0-lite` 建立了模型级配置 `imageModelConfigs`，其中显式声明了：

- `supportedAspectRatios`
- `supportedTiers`
- `sizeTable`

这意味着前端当前展示的比例集合，已经落后于模型真实支持能力。

### 1.2 目标

本次调整目标如下：

- 图片页根据 `imageModelConfigs` 动态渲染模型支持的全部宽高比
- 当模型支持 `3:2`、`2:3`、`21:9` 时，页面能完整展示这些选项
- 切换模型后，自动同步当前可选比例
- 不改动现有图片生成主流程与后端接口字段

### 1.3 非目标

本次不包含以下内容：

- 不在前端增加 `2K / 3K / 4K` 档位选择
- 不改造配置页
- 不调整历史记录存储结构
- 不重做图片页整体 UI

---

## 2. 需求确认

### 2.1 用户确认结论

- 图片页采用“动态渲染全部支持比例”
- 前端应读取模型级配置中的 `supportedAspectRatios`
- 未命中模型级配置的模型，仍保留默认比例展示

### 2.2 成功标准

满足以下条件即视为完成：

- 图片页比例按钮不再只依赖写死的 5 个选项
- `doubao-seedream-5.0-lite` 可展示 `3:2`、`2:3`、`21:9`
- 切换模型后，若当前比例不受支持，自动回退到首个受支持比例
- 历史记录复用时不会选中不受支持的比例

---

## 3. 方案选择

### 3.1 备选方案

#### 方案 A：动态过滤现有比例

保留当前 5 个比例定义，仅根据配置决定显示哪些。

优点：

- 改动小

缺点：

- 无法展示 `3:2`、`2:3`、`21:9`
- 不符合“完整显示全部支持比例”

#### 方案 B：完整比例字典 + 动态渲染

在页面中维护一份完整比例字典，再依据 `supportedAspectRatios` 动态生成当前模型的可选比例列表。

优点：

- 能完整展示模型支持能力
- 比例定义集中
- 与模型级配置天然对齐

缺点：

- 比当前写死数组多一层映射

#### 方案 C：仅在生成前校验

UI 不变，只在点击生成时检查当前比例是否受支持。

优点：

- 实现最快

缺点：

- 交互体验差
- 不满足当前需求方向

### 3.2 最终选择

采用方案 B：完整比例字典 + 动态渲染。

---

## 4. 页面设计

### 4.1 比例数据结构

将 `aspectRatios` 从数组改为完整比例字典，覆盖以下比例：

- `1:1`
- `4:3`
- `3:4`
- `16:9`
- `9:16`
- `3:2`
- `2:3`
- `21:9`

每个比例项包含：

- `label`
- `width`
- `height`
- `icon`

### 4.2 当前可选比例列表

新增一个派生列表，例如 `availableAspectRatios`：

- 若 `selectedModel.modelName` 命中 `imageModelConfigs`
  - 使用对应 `supportedAspectRatios` 从比例字典中取值
- 若未命中
  - 回退到默认比例集合

### 4.3 模型切换行为

当用户切换模型时：

- 若当前比例仍受支持，则保持不变
- 若当前比例不受支持，则自动回退到当前模型支持列表中的第一个比例

### 4.4 历史记录复用

当用户从历史记录中复用生成记录时：

- 先按历史记录中的 `width` / `height` 匹配比例项
- 若匹配到的比例仍受当前模型支持，则选中它
- 否则回退到当前模型支持列表中的第一个比例

## 6. 关键逻辑设计

### 6.1 比例解析逻辑

建议增加以下辅助函数：

- `getDefaultAspectRatios()`
- `getAvailableAspectRatios(modelName?: string)`
- `findMatchingAspectRatio(width, height, list)`

### 6.2 默认回退策略

当以下情况发生时，统一回退到当前可选列表的第一项：

- 当前模型没有配置支持比例
- 历史记录比例与当前模型不兼容
- 当前选中比例已被模型切换淘汰

### 6.3 UI 一致性

以下位置都应使用同一份 `availableAspectRatios`：

- 设置抽屉中的比例按钮网格
- 当前选中的比例标签
- 历史记录复用后的比例恢复

---

## 7. 风险与处理

### 7.1 风险：当前选中比例失效

表现：

- 切换模型后，`aspectRatio` 指向的对象不在新列表中

处理：

- 在 `selectedModel` 或可选比例变化时执行同步回退

### 7.2 风险：历史记录比例无法直接命中

表现：

- 历史记录里存的是 `width` / `height`
- 当前模型不支持对应比例

处理：

- 匹配失败时自动回退到当前模型支持列表的第一项

### 7.3 风险：比例字典和模型配置定义不一致

表现：

- `supportedAspectRatios` 中出现页面未定义的比例

处理：

- 仅从完整比例字典中取值
- 找不到的比例项直接过滤掉，避免运行时报错
